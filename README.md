## Descripción del Proyecto
Este repositorio contiene la implementación del modelo físico de la base de datos para la Red Social Estudiantil Pascualina, desarrollada en **PostgreSQL**. El objetivo de esta tarea fue transformar el modelo lógico previamente diseñado en un modelo físico funcional, aplicando las reglas del lenguaje de definición de datos (DDL).

El modelo consta de 15 tablas, implementando claves primarias simples y compuestas, claves foráneas con reglas de integridad referencial (`ON DELETE CASCADE`, `ON DELETE RESTRICT`) y restricciones `CHECK` para garantizar la calidad de los datos.
